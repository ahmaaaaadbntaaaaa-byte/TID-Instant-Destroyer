# Security Analysis Documentation

This directory contains the technical reports and source codes document the offensive side of cache-based side-channel vulnerabilities.

## Available Documentation:

* **Side-Channel Attack Exploits:** Practical Proof-of-Concept (PoC) source codes simulating cache timing attacks (e.g., Flush+Reload).
* **Attack Execution Reports:** Detailed documentation covering environment setup, execution steps, and cache-line timing analysis.
* **Key Reconstruction Methodology:** Analysis of how an attacker leverages timing leaks to fully reconstruct and extract cryptographic keys.
* **Other Technical Files:** Additional architectural studies and research references supporting the security analysis.
