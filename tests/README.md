
# Automated Test Suite and Live Run Logs (tests/)

This directory contains the raw logs and live execution reports generated by the TID (The Instant Destroyer) automated test suite.

## Directory Structure

* **functional_test_report.txt**
  * What it is: Verification log for 29 different memory buffer sizes (from 1 Byte to 1 MB).
  * Purpose: Proves that TID successfully zeroes out every single byte (0x00) across various allocation sizes without any failures.

* **side_channel_attack_report.txt**
  * What it is: Execution log of a live Flush+Reload cache timing attack simulation.
  * Purpose: Compares TID v1 (RAM wipe only, vulnerable to leaks at ~78 cycles) against TID v2 (RAM + Cache Eviction, secure at ~312 cycles), proving that the attack is completely defeated.

---
Note: All tests were executed inside a live cloud environment (Virtualized Real Hardware) powered by an AMD EPYC 9B14 CPU running Linux 6.14.11.
